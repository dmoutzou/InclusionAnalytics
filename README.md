# Figures of Moutzouris & Duretz (2026)
A collection of scripts that reproduces the figures of Moutzouris & Duretz (2026).
In order to run the script, you need:
- Julia installed, preferably `1.11` or above.
- activate the project. In the package mode of the REPL type: `activate`.
- instantiate the project. In the package mode of the REPL type: `instantiate`.

These scripts call the functions that evaluate the analytical solutions and relies on the package [ExactFieldSolutions](https://github.com/tduretz/ExactFieldSolutions.jl).
